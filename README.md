# F1 Hub

Inoffizielle Formel-1-Web-App: Kalender, Ergebnisse, WM-Stände und -Verlauf, Fahrer- und Teamprofile, Strecken, Teamkollegen-Duelle, Fahrervergleich, Reifen- und Telemetrie-Analyse. Alles im Browser, ohne Anmeldung und ohne Kosten.

Datenquellen: [Jolpica-F1 API](https://github.com/jolpica/jolpica-f1) und [OpenF1](https://openf1.org). Flaggen von flagcdn.com.

Nicht mit der Formel 1 verbunden.
